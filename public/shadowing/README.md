# Pitch shadowing audio

US English synthetic reference takes of the phrase library, generated with eSpeak NG. The reference contour in src/lib/data/shadow-pitch.json comes from the matching take before MP3 encoding. It reports pitch in 60 ms frame steps. The app fetches audio only when a learner asks to hear the target.

Source engine: https://github.com/espeak-ng/espeak-ng
